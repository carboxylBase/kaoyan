## 使用时注意

1. 报题、核对题干和图表时优先使用 PDF。各版本包含第三方排版、扫描件、题解版，不代表官方发布或独立校订。
2. `archived_pages/` 保留网页原文，适合全文检索和查参考解析；不等于一套完整离线站点。页面的脚本、样式、部分图片仍依赖原站。已缓存的少量题图放在 `archived_pages/assets/images/`；原文 `/images/...` 路径可在这里查找，其余图片尚未收齐。
3. 文字归档已发现录入问题，例如 2025 年 408 第 4 题 D 项的“链式树”措辞；遇到不清楚的题意，应对照 PDF，不要直接把文字版当作权威答案。
4. PDF 检查包括文件头、页数与页对象可读取；对典型替换版本和疑似错年文件做了页面渲染抽查。没有逐题复核所有年份的答案，也没有证明每份试卷均无缺页。
