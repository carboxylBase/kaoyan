## 题目

在 32 位计算机上执行下列 C 语言代码，则 ui 的真值为：

```c
short si = -32767;
unsigned int ui = si;
```

A. 2^13 - 1  
B. 2^15 + 1  
C. 2^32 - 2^15 - 1  
D. 2^32 - 2^15 + 1

## 用户作答

我操，你这么一说我想起来了， unsigned int，unsigned long long，就有些算法题在提，它会就是要求你对2的64次方或者2的32次方取模。然后实际上这种时候我们直接用 unsigned int，unsigned long long就可以。然后你想说的就是这个地方其实也是一样的道理，本质上来说只是在转换的同时去做对2的32次方取模这个事情。那这样呢大家就很好理解，是吧。

## 诊断

用户已正确理解负整数转换到 32 位 unsigned int 的本质是对 2^32 取模，并能将其与算法竞赛中利用无符号整数实现模 2^32 或模 2^64 回绕联系起来。虽然没有再次说出选项字母，但所述规则可直接且唯一推出 D，视为正确完成。

掌握度记为 3：经过讲解后形成了正确而可迁移的理解；仍需间隔复测确认能够独立计算具体表达式。

## 正确思路

```text
-32767 mod 2^32
= 2^32 - 32767
= 2^32 - (2^15 - 1)
= 2^32 - 2^15 + 1
```

因此选择 D。无符号整数算术同样按该无符号类型的取值范围加一为模数进行回绕。
