## 题目

下列程序段的时间复杂度是：

```c
int count = 0;
int i, j;

for (i = 1; i * i <= n; i++)
    for (j = 1; j <= i; j++)
        count++;
```

A. O(log n)  
B. O(n)  
C. O(n log n)  
D. O(n^2)

## 用户作答

这个题的话，嗯，首先他说I乘F，那么I就是从1到根号n呗。然后这样一来靠第二种循环，那其实就是1加2加3一直加到根号n。嗯，这个东西显然它的级别是O(n)级别的，所以这个题选B。

## 诊断

结论和推理均正确。用户识别出外层循环的上界为根号 n，并将内层循环的总执行次数表示为从 1 累加到根号 n；这足以独立推出线性时间复杂度。口述中的“I乘F”结合上下文应为对 `i * i` 的指代，不影响推理。

掌握度记为 4：独立作答正确，关键推导完整，未发现知识性或方法性缺口。

## 正确思路

令 m = floor(sqrt(n))。语句 `count++` 的总执行次数为：

```text
1 + 2 + ... + m = m(m + 1) / 2 = Theta(m^2) = Theta(n)
```

因此时间复杂度为 O(n)，选择 B。
